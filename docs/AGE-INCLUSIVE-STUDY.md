# Guided study

The optional guided study view opens from a learning brief. Read, Try, Check and
Plan organize private practice without a timer, score or mastery assessment. An
example can be shown during an attempt. A learner can choose an optional review
date; it does not create a reminder.

## Saved data

Saving appends an encrypted attempt revision containing the selected brief
version, answer, question, private next action and optional review date. Nothing
is automatically submitted to a teacher. Selected-text sharing remains a separate
preview and export action, described in [Education](EDUCATION.md).

Reading size and spacing apply only to the mounted view. The guide does not add
an age field, engagement score or network service.

## Readability and locking

The view uses native controls, named stages, keyboard access, visible focus and
text wrapping. Reading size and spacing complement browser zoom.

The private room has a five-minute inactivity lock. After four and a half minutes,
it offers **Continue studying** or **Lock room now**. Continue can be repeated
without a limit and restores focus and the current draft. Manual lock is immediate.
An expired deadline or clock rollback locks the room on resumption or input.

Browser suspension may delay timers, so a full warning interval cannot be
guaranteed in a backgrounded browser. Unsaved text is lost on lock; save before
leaving. Drafts are not written to persistent storage. See [Unsaved edits](DRAFTS.md).

## Validation limits

Behavioral tests exercise revisions, canceled navigation, draft retention,
locking, selected-data boundaries, labels, keyboard operation and reflow. They do
not measure learning outcomes or establish suitability for every age. Physical
devices and assistive technologies require separate checks; see
[browser and accessibility testing](APPLE-TESTING.md).

Hosted deployments must assess their intended audience, privacy, safeguarding,
retention and accessibility requirements. Avoiding an age field does not resolve
those responsibilities.
